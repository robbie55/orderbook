# orderbook

A low-latency limit order book + matching engine in C++20. Single instrument,
integer-tick prices, direct-indexed price levels over a pooled intrusive-list
allocator, with a single-writer book and lock-free SPSC hand-off between the
feed and matching threads.

> Work in progress. See [`DESIGN.md`](DESIGN.md) for the architecture and the
> staged build plan. Benchmarks table and architecture diagram land at v1.0.

## Build

```sh
cmake --preset debug     # Debug + ASan/UBSan
cmake --build --preset debug
ctest --preset debug

cmake --preset release   # -O3
cmake --build --preset release
ctest --preset release
```

Requires CMake ≥ 3.24, Ninja, and a C++20 compiler (GCC 13+ / Clang 16+).
GoogleTest is fetched via `FetchContent`.
